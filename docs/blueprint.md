# **App Name**: Aijolot

## Core Features:

- Animated UI: Dynamic and visually engaging web experience with scroll-triggered, interactive, and sequenced animations.
- Modern Design: Clean, modern aesthetics with ample white space, crisp typography, and high-quality imagery.
- SPA Experience: SPA-like behavior with fast loading times and seamless transitions using Next.js.
- Animated Hero Section: A hero section featuring an animation of a robot connecting app logos with a wire.
- AI Chat Interface: AI agent called Aijolot to assist users. Aijolot uses its tool to respond accurately and informatively.
- Service Pages: Detailed service pages explaining how each service solves eCommerce problems, with specific CTAs for each service.
- Blog: A dedicated resources/blog section with articles, guides, and industry news, integrated with CTAs for Leo IA.

## Style Guidelines:

- Primary color: Tech Blue (#1E2A78) for a dark and serious background.
- Secondary color: Pilot Gray (#A3A8B0) for secondary typography and icons.
- Primary Text Color: Black Ink (#000000) for primary typography and contrast.
- Mist White: White Mist (#F9F9F9) for light backgrounds or separators.
- Accent color: Maize Yellow (#FFCE00) for vibrant accents and buttons.
- Primary font: Sora for headers, providing a modern and sleek look.
- Secondary font: Inter for body text, ensuring readability and a clean design.
- Scroll-triggered animations for elements fading, sliding, and scaling into view as the user scrolls.
- Interactive UI elements with smooth transitions, hover effects, and animated menus.
- Complex sequenced animations with staggered delays for a polished and coordinated feel.
